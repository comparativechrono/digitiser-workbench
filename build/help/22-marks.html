Marking the picture

Each tool sets one of trace-digitiser's options. The marks are listed under Your marks, where the × beside each takes it out.

ToolWhat it saysThe option
Plot areaWhere a panel's axes are: drag from the y-axis line to the right-hand edge, and from the top to the x-axis line. One box per panel; the sides snap to the axis lines found. With plot areas marked, only those panels are read.plot_area, --plot-area L,T,R,B
Leave outSomething inside a plot that is not data: a legend, a label, an inset, an arrow.exclude, --exclude L,T,R,B
TickClick on a tick, below the x axis or beside a y axis, and type what it stands for. It snaps to the tick marks (and labels) found within a few pixels; the box offers the number read there, if any. Two ticks on an axis set its scale; more are fitted by least squares.x_ref, y_ref, --x-ref COLUMN:VALUE
ColourClick on a line, a point or a bar: only the colours picked are read. It takes the most coloured pixel near the click, not the paper or an edge.trace_colours / colours
Colour bar(Heat maps) the coloured strip of the colour bar, if it isn't found.colourbar
Centre, Ring(Polar plots) the centre, and rings with the values they stand for – two set the radial scale.centre, r_ref
Edit points(After a run of points or a polar plot) take points out, put points in; then save the edited table.–

Ticks, in more detail

  • A tick goes with the plot area beside which you click. Panels stacked on one x axis share the ticks marked under the lowest; panels side by side share the y ticks marked beside the first.
  • With several panels, the command line can't say which panel a tick belongs to: the result then gives the Python, which can (x_ref={1: […], 2: […]}).
  • A log axis: choose log under Axes, and type the values themselves (10, 1000), not their logarithms.
  • Ticks on the right-hand axis set the y scale from that axis – for a line drawn against it (Figure 1a).
  • No ticks at all, and values known at the edges of the plot area? Give them under Axes (y_min, y_max …). Only if the axis ends exactly at those values.
